# 岩石判読

写真と肉眼観察から、岩石（火山岩・深成岩・火山砕屑岩・堆積岩・変成岩・断層岩）の候補をしぼる Web アプリ。
鉱物ではなく、野外や実習で出会う岩石の判読を目的にしている。

**公開ページ：https://z1170099-code.github.io/ganseki-handoku/**（スマホでは共有メニューから「ホーム画面に追加」するとアプリのように使える）

## できること

- **観察チェック**：組織・礫の形・粒の大きさ・面構造・色・見える鉱物・つや・硬さ・塩酸・重さ・磁石・産状に答えると、46 種の岩石から合いそうな順に並べる。合う特徴（✓）と合わない特徴（✗）、次に確かめると絞りこめる項目も出る。電波がなくても動く。
- **AI 判定**：写真（3 枚まで）と観察の答え・場所を Gemini に渡し、候補・根拠・合わない点・現物で確かめることを返してもらう。AI が写真から読み取った特徴を観察チェックに入れることもできる。
- **地質図**：現在地・入力した緯度経度・写真の位置情報から、20万分の1日本シームレス地質図 V2 の凡例を引いて表示し、AI にも参考として渡す。
- **図鑑**：岩石ごとの成因・見分けのポイント・似ている岩石との見分け方・日本での産地。
- **記録**：写真・答え・結果・自分の判定・メモを端末に保存。`.json`（写真入り、端末の引っ越し用）と `.csv`（一覧、Excel 用）に書き出せる。

## AI を使うには

Gemini の API キー（無料枠あり）が要る。[Google AI Studio](https://aistudio.google.com/apikey) でキーを作り、アプリの「設定」タブに貼る。
キーは使う人の端末のブラウザの中にだけ保存され、このリポジトリには入らない。
ほかのアプリと同じプロジェクトのキーだと無料枠を取り合うので、新しいプロジェクトで作るのがおすすめ。

## 判定の考え方

観察チェックは、岩石ごとに決めた「よくある特徴」「ありうる特徴」と答えをくらべた一致度（%）。
肉眼でわかる範囲の目安なので、正確な同定には薄片の偏光顕微鏡観察や化学分析が要る。
とくに玄武岩と安山岩、花こう岩と花こう閃緑岩のように SiO2 量やモード組成で分ける岩石は、肉眼では決めきれないことがある。

## 直し方

- 岩石を足す・説明を直す：`rocks.js` を編集して `python tools/check_data.py`。
- 画面や動きを直す：`index.html`・`app.js` などを編集し、`app.js` の `APP_VERSION` と `sw.js` の `SHELL` を同じ新しい版に上げる。
- テスト：`python tools/check_data.py`（必須）と `python tools/e2e_test.py`（Playwright）。
- 細かい決まりごとは [CLAUDE.md](CLAUDE.md)。
