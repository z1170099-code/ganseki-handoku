記録

記録はこの端末のブラウザの中に保存されます。機種変更やブラウザのデータ削除で消えるので、ときどき書き出してください。

Gemini の API キー

写真の AI 判定に使います。キーはこの端末のブラウザの中だけに保存し、Google への問い合わせ以外には送りません。

キーの取り方
  1. Google AI Studio の API キーのページを開き、Google アカウントでログインする
  2. 「API キーを作成」を押す。ほかのアプリと同じプロジェクトのキーを使うと無料枠を取り合うので、新しいプロジェクトで作るのがおすすめ
  3. 表示されたキー（AIza で始まる）をコピーして、上の欄に貼って「保存」

無料枠では、送った写真と文章が Google のサービス改善に使われることがあります。人の顔や個人情報が写った写真は送らないでください。

AI のモデル

混雑や回数切れのときは、自動で gemini-flash-lite-latest に切り替えてやり直します。
